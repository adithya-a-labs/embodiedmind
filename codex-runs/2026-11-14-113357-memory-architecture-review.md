- Rationale — Prioritize shared action feasibility and a controlled memory ablation because recorded DoorKey failures include valid JSON decisions repeatedly walking into known barriers. Recommend subgoal-aware compact retrieval, provenance and location hypotheses, and bounded verification before considering richer learned memory. Across-episode workflow learning is a distinct experiment due to transfer and evaluation leakage. Keeping the existing episodes as diagnosis and evaluating redesigns on fresh seeds preserves the freeze.
