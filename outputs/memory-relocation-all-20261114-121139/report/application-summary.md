EmbodiedMind is a self-initiated study of how local language-model agents use memory and revise beliefs while navigating partially observable, symbolic MiniGrid and BabyAI worlds. The protocol compares reactive, bounded text-history, structured-memory and belief-revision agents using a shared frozen model, controller, action budget and seeded evaluation. Only the evaluator accesses privileged simulation state. The evidence package currently contains 30 validated episodes across its supplied runs. The planned paired analysis examines static mission success and actions tied to contradicted evidence under controlled custom world changes. The research package preserves agent traces and reproducible figures, including observed task failures. The study addresses planning in abstract simulation and uses frozen model weights throughout.
